# ChatPulse — Telegram (для разработчика)

## Первичная настройка

Пользователь в окне онбординга вводит **только номер Telegram**, код подтверждения
и, если потребуется, облачный пароль 2FA. Он не должен вводить `api_id` и `api_hash`.

Разработчик один раз регистрирует собственное приложение на
https://my.telegram.org → **API development tools**. Не вставляйте ключи
в исходный код, архивы или сообщения чата.

Перед запуском ChatPulse установите локальные переменные среды
(для отладки можно через Visual Studio, Debug > Launch Profiles):

```text
CHATPULSE_TELEGRAM_API_ID=<ваш числовой id>
CHATPULSE_TELEGRAM_API_HASH=<32-символьный hex ключ>
```

Эти значения **не должны** попадать в Git, логи, скриншоты и публичные архивы.
После изменения переменных перезапустите Visual Studio или приложение.

В проекте используется `WTelegramClient` 4.4.9. Установленный пакет
восстанавливается NuGet автоматически. Подключение использует обычный
пользовательский аккаунт (не Telegram-бота).

## Сессия

Сессия записывается в
`%LOCALAPPDATA%\ChatPulse\Data\telegram.session.dpapi`
под дополнительной защитой Windows DPAPI **CurrentUser**.
Не передавайте её другим людям и не копируйте между учётными записями Windows.

В этом патче экран «Первый чат» — заглушка: до настройки хотя бы одного
чата онбординг **не может завершиться**. Выход крестиком или Alt+F4
по-прежнему вызывает подтверждение незавершённой настройки.

## Проверка

1. Запустите ChatPulse, введите имя, откройте шаг Telegram.
2. Введите телефон в формате `+79991234567` (пример, не реальный номер).
3. Введите код, поступивший через Telegram.
4. Если потребуется, введите пароль двухэтапной проверки.
5. Убедитесь, что появилось имя подключённого Telegram-аккаунта.
6. Перейдите на экран-заглушку «Первый чат» и вернитесь назад.
7. Проверьте, что закрытие окна вызывает диалог подтверждения выхода.

При ошибке Telegram приложение показывает сообщение, но **не пишет код/пароль в лог**.
Проверка на Windows с реальным аккаунтом обязательна: в среде подготовки
не было установленного .NET SDK и возможности протестировать WPF/MTProto.
